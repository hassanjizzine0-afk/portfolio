### 🎯 Краткое описание

Разработана полная система управления **5-степенным параллельным роботом (Delta-тип)**. Пользователь задаёт траекторию через GUI, MATLAB рассчитывает обратную кинематику и планирует путь, Arduino управляет моторами с обратной связью по энкодерам.




---





### 🏗️ Архитектура системы

| Уровень | Компонент | Задача |
|---------|-----------|--------|
| **Верхний** | Python GUI (tkinter) | Ввод путевых точек, визуализация |
| **Расчётный** | MATLAB | Обратная кинематика, интерполяция, проверка сингулярностей |
| **Связь** | Python + PySerial | Запуск MATLAB, передача данных на Arduino |
| **Нижний** | Arduino Uno | PID-управление моторами, чтение энкодеров |

---

### 🔄 Рабочий процесс

1. **Ввод:** Пользователь задаёт N точек (X, Y, Z + углы α, β, γ) через GUI.
2. **Расчёт:** MATLAB вычисляет углы Q1–Q5, строит гладкую траекторию (pchip), проверяет сингулярности.
3. **Визуализация:** Python показывает 3D-график траектории.
4. **Передача:** Python отправляет углы на Arduino через Serial (115200 бод).
5. **Исполнение:** Arduino выполняет каскадный PID (позиция → скорость → ток) с обратной связью по энкодерам.

---

## 2. Мобильный робот с ROS и SLAM (AMR)

**Тип:** Научно-исследовательский проект  
**Роль:** Полный цикл разработки — от установки Ubuntu до автономной навигации  
**Статус:** ✅ Работающий прототип

---

### 🎯 Краткое описание

Разработан **автономный колёсный робот** на базе **ROS** (Robot Operating System — операционная система для роботов). Робот способен:

- **Строить карту помещения** с помощью **SLAM** (Simultaneous Localization and Mapping — одновременное построение карты и определение своего положения)
- **Локализоваться** — понимать, где он находится на карте
- **Перемещаться из точки А в точку Б** автономно, без участия человека
- **Читать QR-коды** с помощью камеры
- **Следить за объектом** определённого цвета

**Всё собрано с нуля:** от установки Ubuntu и настройки ROS до интеграции сенсоров и навигации.

---

### 🏗️ Архитектура системы

| Компонент | Что это | Что делает |
|-----------|---------|------------|
| **RPLIDAR A1** | Лазерный сканер | Сканирует пространство вокруг робота, измеряет расстояния до объектов |
| **Raspberry Pi Camera (CSI)** | Камера | Обеспечивает компьютерное зрение: чтение QR-кодов, слежение за цветом |
| **Энкодеры** | Датчики вращения колёс | Измеряют, сколько робот проехал (одометрия) |
| **ROS** | Операционная система для роботов | Связывает все узлы системы в единую сеть |
| **SLAM (SLAM Toolbox)** | Алгоритм | Строит карту и определяет положение робота на ней |
| **Навигация** | Алгоритм | Планирует маршрут и управляет движением к цели |

---

### 🔄 Ключевые узлы ROS

> **Узел (node)** — это отдельная программа в ROS, которая выполняет одну задачу и общается с другими узлами через топики (темы).

| Узел | Задача |
|------|--------|
| **Odometry** | Читает данные с энкодеров, обрабатывает их и публикует информацию о перемещении робота |
| **RPLIDAR Driver** | Получает данные с лидара и публикует их в ROS в виде облака точек |
| **SLAM (SLAM Toolbox)** | Строит карту на основе данных лидара и одометрии, определяет положение робота |
| **TF (Transform System)** | Система координат — связывает все узлы и сенсоры в единое пространство |
| **RViz** | Визуализация данных: карта, положение робота, данные лидара, траектория |

---

   - RPLIDAR A1 (лидар) — для сканирования пространства
   - Raspberry Pi Camera (CSI) — для компьютерного зрения
   - Энкодеры — для одометрии
3. **Настроил SLAM Toolbox** — с использованием одометрии для построения карты
4. **Реализовал навигацию** — движение из точки А в точку Б
5. **Добавил компьютерное зрение:**

6. **Проверил в Gazebo** (симулятор) и на реальном роботе

# 🛹 Hoverboard Robot Control System (AMR)

**Тип:** Инженерный проект  
**Роль:** Полный цикл — от перепрошивки контроллера до автономной навигации  
**Статус:** 🔧 Активная разработка (RC-управление работает, ROS2 в процессе)

---

## 🎯 Краткое описание

Проект по переделке **hoverboard** в полноценного **автономного мобильного робота (AMR)**. Используется оригинальная платформа hoverboard с двумя BLDC-моторами и контроллером на чипе **GD32F103**, перепрошитым кастомной прошивкой `EFeru/hoverboard-firmware-hack-FOC`.

**Что уже реализовано:**
- Перепрошивка контроллера через **ST-Link V2**
- Управление через **RC-пульт** (RadioMaster TX12 + TBS Nano, протокол CRSF)
- Двунаправленная телеметрия

**Что в разработке (этот семестр):**
- Интеграция **Raspberry Pi 4** и **ROS2 Humble**
- Подключение **RPLIDAR A1** для SLAM
- Автономная навигация в неизвестной среде (**SLAM Toolbox + Nav2**)

---

## 🏗️ Аппаратная часть

| Компонент | Характеристики |
|-----------|----------------|
| **Моторы** | BLDC с датчиками Холла, 36 В |
| **Контроллер** | GD32F103 (оригинальная плата hoverboard) |
| **Прошивка** | `EFeru/hoverboard-firmware-hack-FOC` (FOC-управление) |
| **Программатор** | ST-Link V2 (SWD) |
| **Батарея** | 36 В (оригинальная от hoverboard) |
| **Пульт** | RadioMaster TX12 (EdgeTX) |
| **Приёмник** | TBS Nano (Crossfire Nano RX) |
| **Протокол RC** | CRSF (UART, двунаправленный, с телеметрией) |

---

## 🎮 Способы управления

| Способ | Цель | Прошивка | Железо |
|--------|------|----------|--------|

| **ROS2-управление** (в разработке) | Команды скорости от Raspberry Pi | `VARIANT_USART` | USB-to-TTL + Raspberry Pi 4 |
