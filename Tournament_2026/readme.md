### 🤖 Всероссийский турнир по мобильной робототехнике «Новая высота 2026»


**Компетенция:** Мобильная робототехника  

**Категория:** Инженеры  

**Даты проведения:** 17 – 20 ноября 2026 г. 

**Место:** г. Калуга, Федеральный технопарк профессионального образования  

**Роль:** Инженер-программист (Embedded / Control Systems)  

**Стек:** C++, WPILib, Studica VMX & Titan, CAN-шина, FRC Driver Station.

--- 

Разработка программного обеспечения для автономного/дистанционного мобильного робота-санитара (доставка грузов и сбор отходов).

*   **Архитектура ПО:** Написание объектно-ориентированного кода на C++ для управления контроллерами через CAN-шину.
*   **Работа с железом:** Настройка связи между контроллером VMX и драйвером моторов Titan, интеграция квадратурных энкодеров для считывания одометрии.
*   **Управление:** Реализация танкового привода с математической балансировкой скорости колес на основе показаний энкодеров и сигналов с геймпада.
*   **Ограничения:** Разработка велась в условиях отсутствия интернета (офлайн-среда), с использованием офлайн-документации и локальных сборок.
